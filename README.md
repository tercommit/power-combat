# Power Combat (V1)

Jeu de combat 1v1 en 3D low poly, à mains nues, jouable dans le navigateur (Three.js + TypeScript + Vite), avec support manette. Hébergé sur GitHub Pages.

- Spécifications : [`docs/SPECS.md`](docs/SPECS.md)

## Statut

Prototype : **démo CPU vs CPU**. Deux IA (Kai et Brick) s'affrontent en boucle, avec coups, garde, jauge de garde, combos, rounds et HUD. Prochaine étape : M1 (clavier et manette).

## Développement

```bash
npm install
npm run dev      # serveur local (http://localhost:5173)
npm test         # tests unitaires
npm run lint
npm run build    # build de production dans dist/
```
